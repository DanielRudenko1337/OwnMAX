OwnMAX — Windows x64 preview

Основа клиента: MAX 26.38.0.82021. Это изменённая пользовательская сборка,
а не официальный продукт OwnMAX с собственным исходным кодом клиента.
Сервер OwnMAX независим от разработчиков оригинального MAX.

НАСТРОЙКА СЕРВЕРА

1. Распакуйте ВЕСЬ ZIP в отдельную доступную для записи папку пользователя.
   Не переносите max.exe отдельно от DLL и не запускайте его внутри ZIP.
2. Закройте эту сборку, включая значок в трее и фоновый процесс max-service.
3. Откройте server.json в Блокноте рядом с START_OwnMAX.cmd.
4. Замените host на адрес СВОЕГО сервера, а port — на его TCP-порт MAX:

   { "host": "m.example.ru", "port": 8443 }

   m.example.ru — пример, замените его своим доменом. host должен содержать
   только ASCII DNS-имя или IPv4: без https://, пути и :порта.
   Ограничение этой бинарной сборки: НЕ БОЛЕЕ 12 СИМВОЛОВ в host.
   Если IP или домен длиннее, создайте короткий DNS-псевдоним своего сервера.
   Например, m.example.ru занимает 12 символов. IPv6 этой сборкой настройки
   не поддерживается. Допустимый port: 1–65535.
5. Сохраните файл и запустите START_OwnMAX.cmd. Он применит server.json
   через Configure-OwnMAX.ps1 к обеим DLL, EXE и службе, а затем запустит клиент.
   Прямой запуск max.exe до настройки использует заглушку test.invalid.

Файл нативной конфигурации также создаётся в:
   %LOCALAPPDATA%\OwnMAX\config.json
Редактируйте server.json и запускайте START_OwnMAX.cmd при каждой смене сервера:
локальная конфигурация и встроенные адреса будут обновлены согласованно.
Не смешивайте EXE/DLL от разных версий: проверка хешей остановит настройку.

ТРЕБОВАНИЯ К СЕРВЕРУ

Сервер должен слушать TCP-порт из server.json (oneme_tcp_port в .env).
Сертификат TLS должен быть доверенным Windows и подходить выбранному имени
или IPv4-адресу. Настройщик НЕ отключает проверку TLS и не ставит сертификаты.
Домен должен разрешаться на ваш сервер; откройте нужный порт в firewall.
В .env сервера задайте свои публичные адреса медиа и сигнализации.

ВХОД

Введите номер телефона. Шестизначный код входа или регистрации смотрите
в консоли СВОЕГО сервера OwnMAX; он действует пять минут.
SMS и Telegram для доставки тестового кода не используются.

ПРОВЕРКИ И ОГРАНИЧЕНИЯ

Адрес частного сервера удалён из выпуска. test.invalid — нерабочая заглушка.
Проверены ZIP CRC, структура и размер PE, диапазоны изменений, конфигуратор
и смена адреса/порта на тестовых копиях. Интерфейс приложения на реальной
Windows-машине в рамках этого выпуска не запускался: это PREVIEW, не гарантия
совместимости всех функций. Звонки сервера остаются экспериментальными.

Подписи изменённых EXE/DLL отсутствуют; Windows может показать предупреждение
о неизвестном издателе. Установка официального обновления заменяет файлы
и настройки этой сборки; не обновляйте её поверх другим установщиком.
Сторонние DLL и их уведомления сохранены. См. THIRD_PARTY_NOTICE.txt.
