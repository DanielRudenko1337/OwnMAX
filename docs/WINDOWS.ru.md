# OwnMAX для Windows

[English](WINDOWS.md) | **Русский**

Сборка Windows x64 основана на MAX 26.38.0.82021 и распространяется отдельно от серверных исходников. Это **preview**: конфигуратор и структура файлов проверены, но интерфейс клиента на реальной Windows-машине для этого выпуска не запускался.

Скачать: [OwnMAX-Windows-x64.zip](https://github.com/DanielRudenko1337/OwnMAX/releases/download/v0.1.0/OwnMAX-Windows-x64.zip). Контрольная сумма находится в `SHA256SUMS.txt` на [странице релиза](https://github.com/DanielRudenko1337/OwnMAX/releases/tag/v0.1.0).

## Где заменить сервер

1. Распакуйте **весь** ZIP в отдельную папку пользователя, доступную для записи. Все DLL и вложенные папки должны остаться рядом с `max.exe`.
2. Закройте эту сборку, её значок в трее и процесс `max-service`.
3. Откройте **`server.json` рядом с `START_OwnMAX.cmd`** в Блокноте.
4. Вместо заглушки укажите свой адрес и TCP-порт протокола MAX:

```json
{
  "host": "m.example.ru",
  "port": 8443
}
```

`m.example.ru` — пример, замените его доменом, который вы контролируете. Можно указать IPv4. Не добавляйте `https://`, путь или `:порт` к `host`.

**Ограничение этой бинарной сборки — 12 ASCII-символов в `host`.** Если ваш IP или домен длиннее, создайте короткий DNS-псевдоним, ведущий на ваш сервер. Например, `m.example.ru` занимает 12 символов. IPv6 этим настройщиком не поддерживается. Порт может быть от 1 до 65535.

5. Сохраните `server.json` и запустите **`START_OwnMAX.cmd`**.

Лаунчер вызывает `Configure-OwnMAX.ps1`, проверяет хеши файлов, меняет адрес в обеих `config.dll`, `max.exe` и `max-service.exe`, синхронизирует локальную конфигурацию, затем запускает клиент. Для смены сервера достаточно снова изменить `server.json` и запустить лаунчер; вручную править EXE не нужно.

До настройки встроен нерабочий адрес `test.invalid`. Прямой запуск `max.exe` до применения настроек не подключает клиент к вашему серверу.

## Что настроить на сервере

| Настройка | Что требуется |
| --- | --- |
| DNS | `host` должен разрешаться в адрес вашего сервера |
| TCP-порт | `port` должен совпадать с `oneme_tcp_port` в серверном `.env` и быть доступен через firewall |
| TLS | Сертификат должен быть доверен Windows и действителен для выбранного DNS-имени или IP SAN |
| Медиа и звонки | Публичные адреса в `OWNMAX_PUBLIC_URL`, `OWNMAX_MEDIA_URL`, `OWNMAX_SIGNAL_URL`, TURN/STUN задаются на сервере отдельно |
| Доступ к звонкам | Номера перечисляются в `OWNMAX_CALL_PHONES`; звонки экспериментальные |

Настройщик не отключает проверку TLS и не устанавливает сертификаты. При использовании короткого DNS-псевдонима сертификат должен подходить именно этому псевдониму.

Нативный файл настроек создаётся по пути **`%LOCALAPPDATA%\OwnMAX\config.json`**. Его перезаписывает лаунчер на основе `server.json` и `config.template.json`, поэтому для обычной смены сервера редактируйте `server.json`.

## Как войти

Введите номер телефона в клиенте. Код входа или регистрации появится в **консоли вашего сервера OwnMAX**. Код состоит из шести цифр и действует пять минут. SMS и Telegram для доставки тестового кода не используются.

## Проверки и ограничения

В выпуске проверены CRC ZIP, хеши исходных нейтральных бинарных файлов, сохранение размеров и структуры PE, применение конфигурации, повторная смена сервера, порты 1 и 65535, отказ при повреждённых файлах и неверных настройках. PowerShell-настройщик исполнялся на тестовых копиях в Linux; это не заменяет запуск нативного клиента на Windows.

Исходный адрес частного сервера удалён из содержимого релизного ZIP, включая EXE, DLL и инструкции. Пользовательские базы, токены и настройки подключения в архив не включены. Не смешивайте файлы разных сборок: конфигуратор откажется применять изменения к неизвестной версии.

Изменённые EXE/DLL не имеют действующей подписи издателя; Windows может показать предупреждение о неизвестном издателе. Официальное обновление заменяет настройки и файлы этой сборки. Сторонние файлы и их авторские уведомления сохранены; серверная лицензия MIT не перелицензирует клиент MAX и его зависимости. Подробности — в `THIRD_PARTY_NOTICE.txt` внутри ZIP.
